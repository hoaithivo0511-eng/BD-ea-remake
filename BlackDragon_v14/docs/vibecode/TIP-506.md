# TIP-506 — Per-intent async hard timeout (BD-R1)

- Priority: P1
- Depends on: —
- Finding: BD-R1 (`VERIFY_REPORT-v14.7.2.md`)
- Decision: Chu nha, 11/08/2026 — *"giu thu tu, giam hard timeout"*

## Task

`Strategy::OnTick` returns early on `m_exec.HasAnyPendingClose()` **above**
`ApplyGuard(ctx)`, so an async close that never resolves also freezes
Money SL All account / Daily SL. The ordering is deliberate (BD-001/BD-002:
a close is terminal for the tick, and a guard close fired on top of an
unresolved close would double the exit traffic), so it **stays**. What is
reduced is the length of the freeze.

- `Config.mqh`: add `BD_ASYNC_CLOSE_HARD_TIMEOUT_SEC = 10`.
  `BD_ASYNC_HARD_TIMEOUT_SEC = 30` keeps its value and is now documented as
  the OPEN-intent timeout.
- `ExecutionLayer.mqh`: add PURE `Exec_HardTimeoutSec(action)` and use it in
  `Watchdog()` instead of the single shared constant, including in the
  `"wdog"` log line.

## Constraints

- OPEN intents keep 30s. Releasing the busy flag of an unresolved OPEN early
  can produce a **duplicate order** — that risk is not worth 20 seconds.
- CLOSE/MODIFY may release at 10s because both are idempotent:
  `ClosePosition()` re-selects the ticket and returns false when the position
  is already gone, `ModifySlTp()` re-sends identical levels.
- The soft timeout (`BD_ASYNC_TIMEOUT_SEC = 5`), the reconciliation order and
  the "never release while a live server order exists" rule are unchanged.
- Watchdog runs on the 500ms timer, so the effective resolution is unchanged.

## Acceptance

- `Exec_HardTimeoutSec(INTENT_OPEN_BUY)` and `(INTENT_OPEN_SELL)` return 30;
  `INTENT_CLOSE_TICKET`, `INTENT_MODIFY_SLTP` and `INTENT_NONE` return 10.
- Async, `MoneySLAllAccount != 0`: kill the close reply. The guard must fire
  at most ~10s after the soft timeout, not ~30s.
- Async, an OPEN request whose reply is lost: no second order is sent before
  30s, and the journal entry is still released afterwards.
- The `"wdog"` log prints the timeout actually applied (10 or 30), not a
  hardcoded 30.
