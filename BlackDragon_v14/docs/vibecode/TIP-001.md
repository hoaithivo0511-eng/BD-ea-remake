# TIP-001 — Close-terminal coordinator

- Priority: P0
- Depends on: none

## Task

Make every close action terminal for the current `Strategy::OnTick`.

## Constraints

- Process simultaneous BUY/SELL exits.
- Do not change exit decision formulas.
- Do not delay the first close request.
- A pending close blocks entries and real-level modifications.

## Acceptance

- Panel close → return.
- Money guard close → return.
- BUY and/or SELL exit → send applicable closes, then return.
- No later open/DCA/modify intent in those paths.
