# TIP-508 — Manual magic-0 orders: realized P/L in the daily net (BD-R6)

- Priority: P2
- Depends on: —
- Finding: BD-R6 (`VERIFY_REPORT-v14.7.2.md`)
- Decision: Chu nha, 11/08/2026 — *"tinh ca realized cua lenh tay"*

## Task

With `flag_Hand_Ord = true` the position scan accepts magic-0 manual orders,
so their **floating** P/L flows into `dayNet`. `SeedDayProfit()` and
`OnTradeTransaction` accepted only `Magic`, so their **realized** P/L never
was. Net effect: the day total jumped *backwards* the moment a winning manual
order closed — its floating P/L left the basket and nothing replaced it. The
daily TP could be reached and then un-reached by a profitable close.

- `BasketManager.mqh`: add PURE
  `Basket_OwnsMagic(dealMagic, botMagic, handOrders)` and use it in `Rebuild()`
  and `SeedDayProfit()`.
- `BlackDragon.mq5`: use it in `OnTradeTransaction` for the `DEAL_ENTRY_OUT`
  booking.

## Constraints

- One ownership rule, one function, three call sites. Any future site that
  answers "is this ours?" must call it too.
- `flag_Hand_Ord = false` (default) → byte-identical behaviour.
- Symbol filtering is unchanged: only `_Symbol` deals count.
- This widens the documented scope of the **daily** target when
  `flag_Hand_Ord = true`: it becomes "this bot + manual orders on this symbol",
  which is what the floating side already meant. `MoneyTPAll/SLAll` (magic
  scope, floating only) are untouched.
- `m_dayStartBalance = balance - m_dayProfit` stays coherent because both sides
  of the subtraction now use the same rule.

## Acceptance

- `Basket_OwnsMagic(1111, 1111, false) == true`;
  `(0, 1111, false) == false`; `(0, 1111, true) == true`;
  `(2222, 1111, true) == false`.
- `flag_Hand_Ord = true`: open a manual magic-0 order, close it in profit. The
  panel day total must not fall — the floating amount is replaced by the same
  realized amount (± spread/commission).
- `flag_Hand_Ord = true` + `DailyTPMoney` reachable by a manual close alone:
  the halt fires.
- `flag_Hand_Ord = false`: the day total ignores magic-0 deals, exactly as in
  v14.7.1.
- Restart mid-day with `flag_Hand_Ord = true`: `SeedDayProfit()` re-derives the
  same total that was on screen before the restart.
